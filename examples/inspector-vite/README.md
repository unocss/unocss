# UnoCSS Inspector — plain Vite

The minimal setup: a plain Vite app with UnoCSS. No Vite DevTools installed.

```sh
pnpm install
pnpm dev
```

Open [http://localhost:5173/\_\_unocss/](http://localhost:5173/__unocss/) and
enter the one-time code printed in the dev server terminal to unlock the
inspector (the token is remembered per browser).
